## 🔍 使用方法

### Root

```bash
saukko          # 启动机器人框架
saukko stop     # 停止机器人框架
```

### Plugin

```bash
saukko plugin list                          # 列出已安装的插件
saukko plugin install <plugin-dir>          # 安装插件
saukko plugin enable <plugin-name>          # 启用插件
saukko plugin disable <plugin-name>         # 禁用插件
saukko plugin uninstall <plugin-name>       # 卸载插件
```
